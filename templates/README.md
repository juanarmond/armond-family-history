# Templates

Copy these templates when creating new repository records. Replace every
`NNNN` placeholder, remove unused optional fields and retain empty required
arrays.

- `entities/` contains YAML skeletons that correspond to the schemas.
- `person-profile.md` is the human-readable research profile.
- `family-profile.md` is the human-readable family analysis.
- `source-record.md` supports detailed transcription and source evaluation
  alongside the structured source record.
- `research-log.md` records each search session, including negative results and
  access restrictions.

Templates are not data and are not validated as live entities. Never copy
example wording as if it were evidence.
