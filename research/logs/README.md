# Research logs

Create one Markdown file per research session from
`templates/research-log.md`. Use the filename
`YYYY-MM-DD-short-research-question.md`; add a numeric suffix when more than one
session on the same question occurs that day.

Logs are append-only evidence of the search path. Correct factual errors in a
new dated entry or with an explicit correction note rather than erasing the
history.
