# Source data

Store one source per `SRC-NNNN.yaml` file. Allocate source identifiers
sequentially and never reuse a retired identifier. Collaborative trees and
unsourced profiles must use `evidence_class: collaborative_tree` and
`usage: lead_only`.

Private document images remain under `evidence/`; a source record links to the
repository-relative file and captures the archival reference, abstract,
transcription status and reliability assessment.
